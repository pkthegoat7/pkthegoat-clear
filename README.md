- 💬 Abrir e fechar DMs automaticamente

- 💾 Backup de mensagens em HTML
- 🎮 Rich Presence personalizado (RPC)
- 🔍 Scraper de ícones de servidores
- 👤 Visualizar informações de usuários
- ⚙️ Configurações personalizáveis

## 🚀 Instalação

```bash
# Clone o repositório
git clone https://github.com/brunnoxw/brunnoclear.git

# Entre no diretório
cd brunnoclear

# Instale as dependências
npm install
```

## 💻 Uso

### Método Recomendado (Windows)

Execute o arquivo batch para iniciar o programa:

```cmd
start.bat
```

### Método Alternativo

Ou use o comando npm:

```bash
npm start
```

O pkthegoat clear irá guiá-lo através de um menu interativo fácil de usar com todas as funcionalidades disponíveis.

## 📦 Build

### Windows (Método Simples)

Use o script batch para criar o executável:

```cmd
transformar-executavel.bat
```

O executável será gerado na pasta `dist/`.

### Método Manual (Multiplataforma)

```bash
npm run build       # Windows
npm run build:linux # Linux
npm run build:mac   # macOS
```

## 🤝 Como Contribuir

Contribuições são muito bem-vindas! Se você deseja ajudar a melhorar o pkthegoat clear, siga os passos abaixo:

### Enviando um Pull Request

1. **Fork o repositório**
   - Clique no botão "Fork" no topo da página do GitHub

2. **Clone seu fork**
   ```bash
   git clone https://github.com/SEU-USUARIO/brunnoclear.git
   cd brunnoclear
   ```

3. **Crie uma branch para sua feature**
   ```bash
   git checkout -b minha-feature
   ```

4. **Faça suas alterações**
   - Edite os arquivos necessários
   - Teste suas mudanças localmente

5. **Commit suas alterações**
   ```bash
   git add .
   git commit -m "Descrição clara do que foi alterado"
   ```

6. **Envie para seu fork**
   ```bash
   git push origin minha-feature
   ```

7. **Abra um Pull Request**
   - Vá até o repositório original no GitHub
   - Clique em "Pull Requests" → "New Pull Request"
   - Selecione sua branch e descreva suas alterações
   - Clique em "Create Pull Request"
